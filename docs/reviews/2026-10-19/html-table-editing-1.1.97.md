# HTML 表格无法点击修复 · 1.1.97

## 真实文件复现与原因

用户提供的审查文档共 25,102 字节。只读读取，所有编辑验证都在自动测试生成的临时副本中执行；不将原文、文件名或截图入库。

第 2 节的表格是 Knote 生成的 HTML 表格，单元格包含多段落，不能用 GFM 管道表格表示。`serializeTableHtml` 正确将这种结构保存为 HTML，但加载时 `installKnoteMarkdownRawHtml` 将 `<table>` 交给不可编辑的 `knoteRawHtmlBlock` 原子节点。因而整个表可以拖动，单元格却不能进入文字编辑，也不能框选。与普通 Markdown 表格的空白点击定位是不同的原因；旧专项只覆盖管道表格，没覆盖多段落表格保存为 HTML 后重开。

## 修复

- 可由现有表格 schema 完整表示的 HTML 表格回到正常 table / tableCell / tableHeader 模型；保留多段落、合并格、正文格式及对齐。
- 补齐 Knote 生成的文字色、背景色、普通高亮、图片缩放及对齐属性；避免用户加颜色或插图保存后，又把表格读为只读整块。自定义高亮色、非模型支持的图片固定像素样式等仍按原始 HTML 保留。
- 同时恢复原始行号锚点，让编辑表格只重写该表格，不改写前后正文。
- 未知标签、嵌套表格、caption、未知属性/样式、注释等仍按原始 HTML 保留，避免转入不支持它们的 schema 时静默丢失内容。没有广泛放开 HTML 或事件处理属性。
- 修正原生编辑器测试的启动参数顺序，与上一轮桌面夹具修正保持一致，避免把开发入口当成额外工作区。
- 不改用户文档、不迁移文件、不加入轮询或整表鼠标移动扫描。解析检查只在读入对应 HTML 块时执行。
