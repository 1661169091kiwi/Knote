# 选中文字工具栏：应用视窗定位

## 问题与修改

- 工具栏已经 Teleport 到 body，但定位边界仍与编辑器卡片及其滚动祖先取交集。选中首个标题时，工具栏会被挤进标题区域。
- 改为使用整个应用客户区，只避开原生窗口标题栏。导航栏不再充当定位边界。
- 工具栏优先位于选区上方；上方不足而下方足够时翻到选区下方。完全滚出视窗的选区仍保留边缘停靠，不滚动文档、不改变选区。
- 标题使用完整行框，而非较小的文本插入点矩形，避免大字号标题与工具栏光影相碰。
- 全局 `.toolbar-glow` 的 `z-index: 999` 会覆盖 Tailwind 工具类；仅为文字工具栏设置内联层级 1200，使它确实能越过导航栏，仍低于原生标题栏 3000。图片和表格工具栏不变。
- 沿用既有事件触发、单帧合并的定位机制；没有增加持续轮询、观察整棵 DOM 或闲置帧循环。
