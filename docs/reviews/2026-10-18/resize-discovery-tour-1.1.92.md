# v1.1.92：边界提示、拖拽公告与产品教程

## 用户要求与范围

为老用户说明拖拽调整没有移除，只是实际命中区域缩小；悬浮边界就出现调整光标，但必须移动到对应短把手才能拖动。产品教程页增加相关操作说明与动画。本轮没有获得 GitHub 发布或安装授权，不自动发布、安装或修改系统设置。

公告：`docs/releases/v1.1.92.md`，包含可直接使用的中文公告与英文说明。

## 实现

- 左侧栏、编辑区、助手侧栏各增加一个透明的边界提示层。提示层只改变鼠标光标，通过 CSS 相邻选择器显示对应把手，没有 pointerdown/click/dblclick 处理器，不改变宽度、不写盘。
- 提示层是拖动按钮的兄弟节点，不是其子节点，事件不能冒泡触发调整；原全高按钮保持 `pointer-events:none`，真正可拖区域仍为 14×56 / 18×56 CSS px 的短把手。
- 提示层层级 46、实际把手 47，既不被层级 45 的空文档欢迎层遮挡，也不会盖住相邻把手。鼠标离开仍立即隐藏。Android 不显示桌面宽度提示层。
- 不新增鼠标跟踪、定时轮询、布局观察器、resize 计算或持久化路径。
- 产品教程由四步扩展为五步，第四步演示「悬浮边界 → 移到短把手 → 按住拖动」。中英双语，左右区域示意和上下错位说明；支持暂停、重播。
- 动画封装在 `ResizeTourDemo.vue`，仅在该页挂载，离开即销毁；只使用 CSS transform/opacity 动画，无 JS 定时器和逐帧布局。系统减少动态效果时改为静态错位把手示意，隐藏播放控件。
- 保持 `knote-onboarding-complete-v1` 原有完成状态，不让老用户在升级后被强制重放教程。入口仍为「⋮ → 产品教程」。

## 专项测试与修正记录

新鼠标级用例覆盖三条边界上的提示光标、边界其他位置按住移动不调整宽度、提示点亮短把手、真正把手仍可拖动与写盘、离开即隐藏、相邻错位、长文档滚轮、窄屏和 Android 触控。

教程测试验证实际动画时间前进、暂停冻结、重播从头开始、减少动态效果停止动画、中英文文案、780px 窄窗口不横向溢出、完成/退出后恢复页面滚动。

初轮专项测试出现两类测试测量问题：CSSOM 的 URL 引号规范化导致光标字符串比较不一致；教程背景光斑有意越界，不能用整个外层的 scrollWidth 判断内容布局。分别改为规范化 URL 引号、检查实际内容容器及示意图边界，保持行为断言。

实际发现的一处实现问题：空文档欢迎遮罩层级为 45，遮挡了编辑区边界提示。通过 `elementsFromPoint` 确认后修正提示/把手层级，并保留三处真实命中测试。修正前的专项失败不计为通过。
