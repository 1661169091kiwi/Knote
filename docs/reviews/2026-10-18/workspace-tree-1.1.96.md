# 工作区文件树修复 · 1.1.96

## 用户目录与复现

只读检查 `C:\Users\16611\Desktop\GUI_OR_Universal_computer_operate_agent_Survey`，未修改其中的文件。

根目录实际有 111 项，其中 19 个目录、67 个 Markdown 文件。旧实现按深度优先递归所有子目录，全部文件共享 10,000 项 / 12 秒预算；缓存和测试依赖目录耗尽预算后，父目录枚举也提前退出。因此根目录只返回截图中的六个目录，后面的文档没有机会进入文件树。这不是文件损坏，也不是 Markdown 扩展名识别错误。

直接重放旧算法得到 2,927 次目录列举、10,004 个条目及相同的六个根目录。新算法初次打开只列举根目录一次，正确返回 111 项，包括全部 67 个 Markdown 文件。约 12.8 ms 是本地 Node 元数据列举时间，不是完整 Electron 界面打开耗时。

## 修复内容

- 打开工作区只读取当前层，完整列举后才显示，展开目录才读取其直接子项。
- 同一目录的并发展开合并；加载完成后缓存；失败允许重试，切换工作区后的迟到结果不安装到新树。
- 保留原来的固定生成目录排除策略，不额外隐藏 `.test-deps` 等用户目录。
- 显式全量索引改为广度优先；预算只在完整层之间检查，不能再截断父层文件。索引不全仍明确标记，Agent 不会将未扫描子树误认为空目录。
- 全文搜索独立索引未展开目录；已知工作区文件可以通过受限的只读路径解析访问，不依赖 UI 是否展开。路径穿越和原有类型限制保留。
- 刷新后恢复已展开目录；普通侧栏与浮动文件树都提供按需加载状态。
- 本地版本提升为 1.1.96，包含上一轮尚未发布的表格空白点击定位修复，不覆盖公开的 1.1.95 安装包。

未加入常驻后台全树扫描、轮询或 WMI / taskkill 调用。
