# v1.1.91：隐形尺寸把手与中英文工具栏

## 用户确认与最终设计

用户采纳统一尺寸把手方案，随后否决了常驻白色胶囊外框，要求参考助手浮窗并及时隐藏；又指出初版隐形把手悬浮时太淡、编辑区头尾角点不方便，要求仅用垂直错位区分。最终默认透明，悬浮/键盘聚焦/拖动时显示更清楚的绿色短线及局部浅绿光晕；离开后不播放退场动画，立即隐藏。

- 侧栏、助手侧栏：中段 4×40 CSS px 的短线，透明热区 14×56 px。
- 编辑区：同样 4×40 px 短线，在当前窗口中段与侧栏错开高度；不保留头尾角点，不新增文档高度调整。
- 助手浮窗：四角继续调宽高，两边中点只调宽度；没有新增原本不存在的分栏分隔拖动器。
- 裁剪控件仅在裁剪状态出现；块拖动仍只针对当前块。均未改变拖动语义。
- 全高轨道 pointer-events:none，只有小把手 pointer-events:auto，避免相邻全高命中区域重叠。
- 视觉状态仅由 CSS hover/focus 和一次手势开始/结束的 data-resizing 控制；不新增鼠标跟踪、轮询、持续动画或布局观察器。

## 已发现并修正的初版回归

1. 编辑区把手一半覆盖在空文档提示层下，实际鼠标中心被提示层命中，拖动宽度不变。已提高编辑区把手层级，并在测试中断言 elementFromPoint 命中实际把手。
2. 按钮默认内容排版将 sticky 子把手置于长文档中部，滚动后可能离屏。按钮改为从顶部排布的 flex track，短把手 sticky 到可视窗口；测试覆盖 160 段文档滚动 1800px 后三处把手均在窗口内。

## 工具栏

格式行的按钮和下拉触发器使用 flex 分配多余空间，颜色按钮填满自己的槽位；不会把八个按钮强制设置成一种固定宽度，也不会截短英语 AI 功能名称。颜色面板仍 right 对齐，不计入主工具栏宽度。语言变化时仅重新计算一次可视窗口位置。

中英文原生测试验证 A 的实际按钮右边界等于格式行右边界，首按钮与左边界齐平；调色板打开后不改变主工具栏宽度且保持右对齐。普通/长文档工具栏停靠回归一并保留。
