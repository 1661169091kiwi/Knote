# 宽表格水平滚动条修复 · 1.1.99

## 原因与复现

表格 `.tableWrapper` 继承了 `.knote-root` 的 `scrollbar-color`。页面滚动停止约 900 ms 后根元素变透明，表格横向滚动条也被隐藏；表格滚动并未被全局滚动条处理器识别，按住/横拖不能维持显示。

后台原生鼠标诊断确认：按住 1300 ms 后颜色变为全透明，但节点、尺寸、选区不变，继续拖动仍能将 `scrollLeft` 从 0 改成 348。日志 `table-scrollbar-diagnosis-1.1.98.log`。

新增回归在旧 1.1.98 ASAR 上先失败，失败点为表格错误继承页面的绿色显示状态；原有表格用例 5/5 通过。基线专项总计 5/6，日志 `table-scrollbar-before-fix-1.1.98.log`。

## 局部修复

- 为表格显式设置自身的透明/显示颜色，不再继承页面计时状态。普通主题沿用浅绿，复古主题使用既有金色。
- `bindTableScrollbar` 仅监听本表格的进入、离开、按下和滚动；按下原生水平滚动条后，临时监听窗口释放/取消/失焦。按住即使移出表格也不隐藏；在表格内释放仍保持悬浮显示，离开后再计时 900 ms。
- 不取消或拦截原生鼠标事件，不调用编辑器命令，不接管滚动位置，不改变表格布局。
- NodeView 销毁时清除计时器、表格监听和临时窗口监听。没有全局常驻鼠标跟踪、DOM 扫描、轮询或闲置 RAF。
- 只忽略 wrapper 上与显示有关的 class/data 属性变动，避免悬浮导致整表 DOM 重解析；单元格、正文及其他 mutation 仍正常进入 ProseMirror。连续滚动不重复写入相同 class。
- 显示标记只在 NodeView DOM 上，不进入表格 schema 或 Markdown 保存结果。
