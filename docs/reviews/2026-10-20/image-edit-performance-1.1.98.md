# 图片编辑卡顿修复 · 1.1.98

## 范围

修复上一份诊断记录 `image-edit-lag-diagnosis.md` 的两个热点。保留用户已确认的 HTML 表格修复及选区工具栏应用视窗定位；不改用户原文，不自动安装或发布。

## 实现

- `htmlImageTags.js` 通过原生分隔符搜索和 `indexOf` 跳过完整引号值，保留源偏移，避免在长标签上逐字符执行重复分支；遇到残缺引号停止，遇到未加引号的嵌套 opener 线性前进，不反复扫描同一段。
- `imagePathMapping.js` 除替换标签扫描外，进一步移除 `src` 值扫描中的惰性 `.*?` + 引号反向引用。仅更改第一层标签定位未消除约 200 ms 热点，复测后定位到内层 `src` 扫描，现使用单双引号各自的原生否定字符集合跳过值。
- 只替换确实变化的图片标签；未变化的标签、实体、样式、其他正文及代码示例保留原始字节。资源认证标记、相同字节不同路径的隔离规则及代码段保护保持不变。
- `markdownRawHtml.js` 仅在有准确源行映射、内容确为单独一个完整 HTML 图片时，用携带源行属性的段落承载它。图片在当前 schema 中是 inline；只给 `<img>` 加标记不能为宿主块恢复锚点。非锚定渲染、混合 HTML、多图及残缺内容不做猜测包装。
- 不移除未知锚点回退保护，不用猜测位置替换源行；没有增加全局轮询、鼠标移动扫描或常驻帧循环。
