# Knote 1.1.63：居中编辑区回归修复

## 根因

1.1.62 在拆分左右侧栏宽度时移除了对称占位，并把编辑器设置为在侧栏之间的剩余空间中居中。左栏 280 px、Agent 420 px 时，编辑器因此向左偏移 70 px；开关名称仍为“居中编辑区”，实际语义却已经改变。

## 修复

- 居中模式重新以可见应用工作区中心为基准，不受原生滚动条宽度影响。
- 仅左栏或仅 Agent 栏可见时，使用等宽的无交互镜像占位。
- 两栏同时可见且宽度不同时，只补偿两栏的宽度差，不强制把左栏加宽到 Agent 栏宽度。
- 居中模式对可见侧栏增加空间上限，保证补偿后编辑器仍至少保留 320 px；拖动过程仍然只更新 CSS 变量，松开才持久化。
- 关闭居中模式时继续使用紧凑工作台布局，不启用补偿。

## 验证范围

- 左右栏同时显示且宽度不同。
- 仅左栏显示。
- 仅 Agent 栏显示。
- 两栏隐藏。
- 左右栏拖动、松开持久化、刷新恢复和双击复位。

## 验证结果

- `npm test`：通过。
- `npm run test:electron-ui`：83/83 通过；真实 Electron 窗口中验证了双栏、单栏、拖动、刷新后的可见画布居中。
- `npm run test:editor-native`：4/4 通过。
- `npm run dist:win`：通过。
