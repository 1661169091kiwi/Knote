# Knote v1.1.98

## 图片编辑性能

- 修复已缩放、居中或靠右保存的 HTML 图片在重开后缺失源行定位的问题，避免再次调整图片时退回全文序列化。
- 优化大图片地址的 HTML 扫描，减少长 Base64 引起的主线程阻塞。
- 保留原图片相对路径、标题、对齐和缩放信息；局部编辑不重写其他正文。

## 编辑器交互

- 选中文字工具栏可以越出编辑区，按整个应用视窗定位；上方空间不足时移到选区下方，避免遮住顶部标题，并修正导航栏覆盖工具栏的问题。
- 包含 v1.1.97 的 HTML 表格修复：Knote 保存的多段落、合并单元格表格重新打开后，可继续点击、编辑和框选单元格。
