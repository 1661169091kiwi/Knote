# Knote v1.1.101

## 新主题：玻璃

- 主题菜单新增「玻璃 · 浅色」和「玻璃 · 深色」两个选项。原有明亮、暗黑主题保持不变。
- 界面改用近灰色的层级底色区分结构，不再依靠边框；页面中的卡片不带阴影；选中项、开关和主要操作统一使用 iOS 蓝。
- 浮在内容上方的界面采用液态玻璃效果：菜单、右键菜单、提示条、分栏模式的悬浮侧栏，以及桌面版标题栏。桌面版（Chromium）会折射背后内容，其他环境退回普通磨砂。
- 悬浮的 AI 助手窗口整体是一块液态玻璃：背后的文档会模糊、折射地透出来，窗内的分组、输入框和对话气泡改为半透明填充；为保证文字可读，玻璃比菜单更厚（浅色 72%、深色 78%）。调整窗口大小时先显示普通磨砂，停下后再恢复折射，拖动不卡顿。
- 玻璃主题下，标题栏同样有缓慢流动的光晕（蓝、青、淡紫）；应用图标、导出 PDF / Word 图标换成蓝色猕猴桃；更新菜单、分片编辑卡片、助手会话标题、上下文用量圆环、问题导航栏等残留的绿色全部改为玻璃配色。
- 助手的「光晕」聊天主题在玻璃主题下保留缓慢流动的光晕，配色改为蓝、青、淡紫；「白色」主题保持纯净。经典主题的黄绿光晕不变。
- 玻璃主题下助手窗口四角的调整把手沿窗口圆角绘制并带柔和光晕，可拖动的位置与显示位置一致。
- 菜单收起时也有动画：顶栏下拉菜单、右键菜单、侧栏「⋯」弹出菜单和助手里的会话、审阅模式弹窗，会快速收回到打开它的位置，不再瞬间消失；侧栏弹出菜单从按钮处展开，右键菜单从鼠标位置展开。经典主题下菜单行为不变。
- 修复代码块语言菜单滚动时自动关闭（滚动条显隐的状态不再写入文档内部，也只在玻璃主题下生效）。
- 玻璃主题下选中文本时，编辑区四周不再出现蓝色焦点框；文字工具栏的「H」「A」悬停菜单不会在展开时突然收起，圆角与工具栏一致。
- 助手面板、设置、输入框和弹窗按同一套层级重新配色；对话框改为实心卡片，背景遮罩不再模糊。

## 调整栏宽

- 悬停、聚焦或拖动侧栏、编辑区、助手侧栏之间的调整把手时，被调整的那一栏会显示主题色描边；左侧栏与编辑区共用一条缝隙的两个把手不再分不清。
- 悬浮助手换成蓝色调的「赛博猕猴桃」：蓝色果肉、青色霓虹边光与发光籽点、闪烁的天线灯，对话气泡改为深色霓虹样式；动作和状态与原版一致。
- 整套鼠标光标（箭头、手形、文本、缩放、等待等 16 种）在玻璃主题下改用蓝色点缀，深色下使用中性底色；形状与热点不变。
- 主题选择会被记住，重启后仍然生效，并在应用加载前应用，避免闪烁。
- 跟随系统的“减少透明度”“提高对比度”“强制颜色”和“减少动态效果”设置，自动改为实色面板或关闭动画。

## 空行显示与 Typora 一致

- 两段之间的一个空行只是 Markdown 的分段标记，编辑器里不再显示成空白行；多出来的空行才显示为空白行（源码里每多一个空行，编辑器里多一行空白）。普通 Markdown 文档（包括内置教程）打开后不再出现成片的空隙。
- 按 Enter 新建段落时保存为标准的「空一行」，其他 Markdown 工具也能识别为两个段落；Shift+Enter 在段落内换行。
- 编辑段落、在空白行里输入、删除段落时只改写受影响的区域，空行数量保持正确，重新打开不会多出空白行；删除整段也不再触发整篇重写。
- 文件开头和结尾的空行仍显示为空白行，打开再保存字节不变。
- 教程新增「段落与换行」一节（中英文），说明空行的显示方式。
- 取代 1.1.100 中「相邻段落保存为单个换行」的做法；该版本修复的「回车后重新打开多出空行」问题在新规则下同样不会出现。

## 布局与滚动条

- 居中编辑区时，宽窗口下左右侧栏会自动加宽填满编辑区两侧的空间（最多 30rem），不再留下大段外侧空白和侧栏与编辑区之间的空隙；手动拖宽的侧栏保持原宽度，编辑区仍保持居中。
- 去掉所有滚动条两端的小三角箭头（圆角卡片会把下方箭头截断）；助手对话的滚动条改为细长圆角样式，悬停时浅灰、滚动时主题色，深色下不再有不透明轨道。
- 助手问题导航栏：点击某个问题后高亮保持在该问题上，不再在滚动途中闪烁跳动；展开的导航栏不再实时模糊背景，滚动更流畅；指针掠过边缘时不会反复展开收起。

## 问题修复

- 安卓手机端：超过一屏的文档会溢出白色卡片且无法上下滑动，现在文档在卡片内滚动，最后一行也能完整看到（#27）。
- 代码块语言下拉按钮不再随长代码行的横向滚动漂移，手机和桌面都固定在代码块右上角（#26）。
- 同一个列表里混有普通项和任务项（`- 说明` 后紧跟 `- [x] 完成`）时，不再凭空多出一个空的 `- [ ]` 任务项，编辑其他内容也不会再触发整篇重写。

此版本不包含曾试验过的可选 Harness 执行引擎。
