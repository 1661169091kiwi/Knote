# Knote v1.1.105

## 超长文档不再分页

- 超过连续编辑上限（约 60 万字符）的文档也不再分页：所有分段在单栏、分栏和 Android 上连成一整段滚动。光标所在的段落可以编辑，其他段落以同样的排版显示，只渲染视口附近的部分；8 MiB 的文档也能流畅滚动。
- 点击任意位置即可在原地编辑，所点的行不移动；方向键可以直接移到上一段或下一段。页码选择器和“分片富文本编辑”卡片已移除。
- 分栏模式下左右两栏各自滚动，右侧预览也是连续的整篇文档，并跟随正在编辑的段落；在单栏和分栏之间切换时，屏幕顶部保持同一段内容。
- Mermaid 图表在滚动到附近、并且滚动停下后才渲染，长文档打开和滚动不再卡顿。连续编辑的上限按实测重新校准：一篇 35 万字符、含 161 张图表的文档现在用连续编辑器打开。
- 查找与替换覆盖整篇文档：计数包含所有段落，其他段落里的匹配同样高亮，回车会跳到下一个有匹配的段落；全部替换覆盖所有段落，不会改动链接地址、图片和 HTML 标签。
- 导出 PDF 始终包含完整文档，以及各段落中刚输入、尚未保存的内容。

## 编辑时保留原文格式

- 编辑超长文档时只重写被修改的段落，其他每一行都保持原样。此前会重写整个分段，去掉每行末尾的空格。被编辑的那一行也保留原来的行尾空格。
- 普通文档重新载入后（例如恢复的标签页），编辑同样只重写改动的段落。

## 界面语言与 Linux

- 页面语言跟随界面语言，界面语言的选择会被记住；中文标点在 Linux 上以正确的全角位置显示。笔记内容按自身语言标记，夹带少量日文或韩文的中文笔记仍使用中文字形（PR #30，感谢 Fogjw）。
- Linux 上标题栏不再遮挡应用内容（PR #29，感谢 Fogjw）。

## 其他

- 修复了长对话在新消息到达时偶尔不再自动滚到底部的问题（排版完成时列表的微小位移被误当成向上翻阅）。
- 玻璃主题下，标题栏的下载更新按钮改为玻璃主题配色。
- 安装新版本后，自动删除下载目录中的旧安装包。
