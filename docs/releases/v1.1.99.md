# Knote v1.1.99

## 表格交互

- 修复宽表格水平滚动条按住后意外消失的问题。
- 表格滚动条不再跟随页面滚动条一起隐藏；悬浮、按住或拖动时保持可见，松开并移开后延迟隐藏。
- 保留原生水平拖动，不改变表格内容、单元格选择或布局宽度。
- 修复 Knote 保存的 HTML 表格重新打开后被识别为只读整块的问题，支持的表格可继续点击、编辑和框选单元格。

## 图片编辑性能

- 修复已缩放、居中或靠右保存的 HTML 图片重开后缺失源行定位的问题，避免再次调整图片时退回全文序列化。
- 优化大图片地址的 HTML 扫描，减少长 Base64 引起的主线程阻塞。
- 保留原图片路径、标题、对齐和缩放信息；局部编辑不重写其他正文。

## 文字工具栏

- 选中文字工具栏按整个应用视窗定位，不再受编辑器卡片边界限制。
- 上方空间不足时移到选区下方，避免遮住顶部标题，并修正导航栏覆盖工具栏的问题。
