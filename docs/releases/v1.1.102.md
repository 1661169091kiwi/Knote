# Knote v1.1.102

## 问题修复

- 修复 1.1.101 中宽窗口下三个调整把手（左侧栏、编辑区、助手侧栏之间）都拖不动的问题。原因是居中布局的工作区上限随栏宽一起变化，拖动时工作区跟着改变宽度，被误判为窗口缩放而立即取消了拖动。现在只有窗口本身改变大小才会中断拖动。
- 宽窗口下自动加宽、填满编辑区两侧的侧栏现在也能单独拖动：左侧栏和编辑区之间的两个把手重新各管各的，拖左侧栏把手只改变左侧栏宽度，拖编辑区把手只改变编辑区宽度；助手侧栏同理。
- 把侧栏拖得比自动填满时更窄，它会保持你拖出的宽度，与编辑区之间留出间隙；把它拖回到编辑区边缘，或双击把手恢复默认，它会重新自动填满。键盘方向键同样适用。
- 左侧栏可拖动的最大宽度从 400px 调整为 480px，与自动填满的上限一致，抓住已填满的侧栏时不会突然跳窄。
- 新增自动化测试：在 2300px 宽的窗口里依次拖动三个把手，确认都能拖动、每个把手只改变自己那一栏、编辑区保持居中，侧栏拖回编辑区边缘或双击后重新填满。
