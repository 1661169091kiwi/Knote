# Knote v1.1.103

## 长对话不再卡顿

- 找到并修复了一个拖慢整个应用的问题：一条 DaisyUI 下拉菜单样式规则让页面上任何元素切换 class 时都会重新计算整页样式（160 条消息时每次约 90ms）。滚动助手对话、流式输出、在编辑器里打字都在付这个代价。现在构建时会改写这条规则，下拉菜单的表现不变。
- 超过 60 条消息的长对话只挂载视口附近的消息：打开 400 条消息的会话从约 1.4 秒降到约 0.1 秒，问题导航栏仍可跳转到任意问题。较短的对话保持全部挂载，屏幕外的消息跳过排版和绘制。
- 流式输出跟随到底部时每帧最多滚动一次，不再每段输出都让整个对话重新排版。向上滚动阅读时，新消息和流式输出不会把你拉回底部；回到底部后自动恢复跟随。
- 输入框改用 CSS 自动增高，打字时不再重新渲染整段对话；Markdown 渲染缓存改为按最近使用淘汰，流式草稿使用单独的小缓存，不会挤掉已渲染的消息。
- 实测 400 条消息：打字延迟（p95）从 208ms 降到 24ms；流式输出卡顿帧从 11/19 降到 1/267；滚动卡顿帧从 43/241 降到 0。

## 长文档连续编辑

- 长文档不再从 32,000 字符起就分页：一般在 60 万字符以内（结构密集的笔记约 43 万字符）都在一个连续的编辑器里打开，可以直接滚动、跨段选择和撤销；只有更大的文档才回到分页编辑。
- 长文档里屏幕外的段落跳过排版和绘制；标题折叠按钮和代码块语言菜单不受影响。从大纲或搜索跳转时，会在周围段落渲染完成后自动校准位置。
- 实测：25 万字符打字 p95 24ms、回车 56ms、打开约 0.4 秒；50 万字符打字 40ms、回车 96ms、打开约 0.85 秒。20 万字符以上的文档打开时显示加载提示。
- 导出（PDF、Word、HTML、Markdown）始终使用完整的 Markdown 源文本，并先写入刚输入的内容，与编辑器是否分页无关。

## 问题修复

- 设置为居中或右对齐的图片，在导出 PDF 和分栏预览中显示在左侧。
- 玻璃主题下，图片工具栏的缩放滑块和对齐按钮、导出 PDF 弹窗仍是绿色，现改为玻璃主题的蓝色配色。
- 分栏模式下，右侧预览的联动高亮改为浅色底加虚线下划线，全选左侧时不再像两侧内容都被选中。
- 助手设置右上角新增关闭按钮（PR #28，感谢 yaozan153）。
